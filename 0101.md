# Ejercicio 1 — Diseño con Tarjetas CRC (Biblioteca)

## 1. Tarjetas CRC

### Clase: `Libro`

| Responsabilidades | Colaboradores |
|---|---|
| Conoce su **título**, **autor**, **ISBN** | `Préstamo` |
| Conoce el **número de ejemplares disponibles** | |
| Sabe si **hay ejemplares disponibles** | |
| **Prestar** un ejemplar (si hay disponibles, descuenta uno) | |
| **Recibir la devolución** de un ejemplar (suma uno) | |

### Clase: `Socio`

| Responsabilidades | Colaboradores |
|---|---|
| Conoce su **nombre**, **número de socio** y **fecha de alta** | `Préstamo` |
| Sabe qué **préstamos tiene activos** | |
| **Solicitar un préstamo** de un libro | |
| **Solicitar un devolución** de un libro | |

### Clase: `Préstamo`

| Responsabilidades | Colaboradores |
|---|---|
| Conoce el **socio**, el **libro**, la **fecha de préstamo** y la **fecha de devolución** | `Libro` |
| Sabe si está **activo** o **devuelto** | `Socio` |
| **Crear el préstamo** pidiendo al `Libro` que preste un ejemplar | |
| **Registrar la devolución** y avisar al `Libro` | |

---

## 2. Operación "prestar" de la clase `Libro`

**Comprobación previa:** se verifica que `ejemplaresDisponibles > 0`.

| Situación | Qué cambia en el objeto `Libro` | Resultado devuelto |
|---|---|---|
| **Éxito** (hay ejemplares) | `ejemplaresDisponibles` disminuye en 1 | el `Préstamo` se crea |
| **Fallo** (0 ejemplares) | **No cambia nada** | no se crea el `Préstamo`|
---

## 3. Flujo paso a paso

| Paso | Acción | Clase que actúa | Colaboradores necesarios | Ejemplares disponibles | ¿Éxito? |
|---|---|---|---|---|---|
| 1 | Alta de un libro con 3 ejemplares | `Libro` | — | **3** | — |
| 2 | Alta de dos socios (Socio 1 y Socio 2) | `Socio` | — | 3 | — |
| 3 | Socio 1 toma prestado el libro | `Socio` → `Préstamo` | `Libro` (prestar), `Socio` | **2** |  **Sí** (3 > 0) |
| 4 | Socio 2 intenta tomar el mismo libro | `Socio` → `Préstamo` | `Libro` (prestar), `Socio` | **1** | **Sí** (2 > 0) |
| 5 | Socio 1 devuelve el libro | `Préstamo` | `Libro` (recibir devolución) | **2** | — |
| 6 | Socio 2 vuelve a intentar tomar el libro | `Socio` → `Préstamo` | `Libro` (prestar), `Socio` | **1** | **Sí** (2 > 0) |
